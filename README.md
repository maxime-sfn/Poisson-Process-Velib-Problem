# Poisson Process – Vélib' Problem

## Project Overview

This project explores the modelling and analysis of a bike-sharing system using **Poisson processes and queueing theory**.

The objective is to study the stochastic dynamics of bike availability and demand, using mathematical modelling and computational methods.

## Repository Structure

- **`rendu.ipynb`** — The main Jupyter notebook containing all the mathematical derivations, modelling assumptions, methodology, and Python code used throughout the project.
- **`Presentation-final.pdf`** — The final presentation prepared for the oral project presentation, summarizing the approach and results.
- **`data/`** — The data used for the analysis and modelling.

## Where to Start

For a detailed understanding of the mathematical framework, assumptions, implementation, and analysis, refer to **`rendu.ipynb`**.

For a concise overview of the project and its main findings, see **`Presentation-final.pdf`**.
